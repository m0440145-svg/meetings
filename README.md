# منصة الاجتماعات الذكية

منصة عربية RTL لإدارة اجتماعات مجلس الإدارة واللجان في جمعية الإحسان للخدمات الاجتماعية.

## الوظائف الحالية
- تسجيل دخول متعدد المستخدمين عبر Supabase (كلمة مرور أو رمز OTP).
- الاجتماعات وجدول الأعمال والمرفقات، الأعضاء واللجان، التصويت، المحاضر والتوقيع، المهام، الإشعارات والبريد الداخلي — محفوظة مركزيًا في Supabase.
- أدوات تجريبية ما زالت تحفظ في المتصفح فقط: مركز المرفقات، استطلاع المواعيد، القرارات بالتمرير، غرفة البيانات.
- تصميم بهوية الجمعية: `#cf6028` و `#f18927` و `#afa5a2` و `#f9f4ee`.

## بنية الملفات
| الملف | الدور |
|---|---|
| `script.js` | الواجهة والتنقل والأدوات التجريبية المحلية. عند وجود `data-backend="supabase"` على وسم `<html>` يتوقف عن عرض وحفظ البيانات المركزية محليًا. |
| `home.js` | يحمّل بقية السكربتات بالترتيب. |
| `supabase-config.js` | عنوان مشروع Supabase والمفتاح العام فقط. |
| `supabase-app.js` | الدخول، الاجتماعات، الأعضاء، اللجان، المهام، الإشعارات، البريد. |
| `advanced-supabase.js` | التصويت، المحاضر والتوقيع، الحضور، الدعوات، البحث. |
| `production-features.js` | OTP، مساعد الذكاء الاصطناعي، تشغيل طابور الإرسال. |
