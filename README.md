# منصة الاجتماعات الذكية

منصة عربية RTL لإدارة اجتماعات مجلس الإدارة واللجان في جمعية الإحسان للخدمات الاجتماعية.

## الوظائف الحالية
- تسجيل دخول متعدد المستخدمين عبر Supabase (كلمة مرور أو رمز OTP).
- الاجتماعات وجدول الأعمال والمرفقات، الأعضاء واللجان، التصويت، المحاضر، المهام، الإشعارات والبريد الداخلي — محفوظة مركزيًا في Supabase.
- في فرع المراجعة: ربط مركز المرفقات واستطلاعات المواعيد والقرارات بالتمرير والتفريغ والسبورة بقاعدة البيانات، مع ترحيل SQL مرشح يحتاج اختبارًا على مشروع Supabase منفصل قبل النشر.
- تصميم بهوية الجمعية: `#cf6028` و `#f18927` و `#afa5a2` و `#f9f4ee`.

## بنية الملفات
| الملف | الدور |
|---|---|
| `script.js` | الواجهة والتنقل والأدوات التجريبية المحلية. عند وجود `data-backend="supabase"` على وسم `<html>` يتوقف عن عرض وحفظ البيانات المركزية محليًا. |
| `home.js` | يحمّل بقية السكربتات بالترتيب. |
| `supabase-config.js` | عنوان مشروع Supabase والمفتاح العام فقط. |
| `supabase-app.js` | الدخول، الاجتماعات، الأعضاء، اللجان، المهام، الإشعارات، البريد. |
| `advanced-supabase.js` | التصويت، المحاضر والتوقيع، الحضور، الدعوات، البحث. |
| `production-features.js` | OTP، مساعد الذكاء الاصطناعي، تشغيل طابور الإرسال. |

## تجهيز الاستضافة
راجع [دليل الاستضافة](docs/HOSTING.md). يتوفر بناء معزول للواجهة وخادم لـRailway، ونشر يدوي مشروط بالاختبارات إلى GitHub Pages.

```sh
npm ci --ignore-scripts
npm test
# عيّن SUPABASE_URL وSUPABASE_PUBLISHABLE_KEY في بيئة الاستضافة
npm run build
npm start
```

البريد الخارجي وواتساب والتوقيع الرسمي غير مفعلة في نسخة المراجعة. تجهيز الاستضافة لا يعني اكتمال معالجة متطلبات قاعدة البيانات: راجع [تقرير الوصول](docs/ACCESS-PHASE.md) و[تقرير الجاهزية](docs/READINESS.md).

## دورة الاجتماع والاسترجاع
راجع [تقرير التنفيذ والاختبار](docs/CENTRAL-LIFECYCLE.md) و[إجراء الاسترجاع](docs/RESTORE-RUNBOOK.md). اجتاز الفرع 29 اختبارًا محليًا؛ لم يُطبّق الترحيل على الإنتاج.
