# منصة الاجتماعات الذكية

منصة عربية RTL لإدارة اجتماعات مجلس الإدارة واللجان في جمعية الإحسان للخدمات الاجتماعية.

## الوظائف الحالية
- صفحة هبوط وتعريف بالمنصة.
- عرض الخدمات والأهداف.
- دعم عرض الجوال والحاسب.
- واجهة أولية لدخول الأعضاء.
- تصميم بهوية الجمعية: `#cf6028` و `#f18927` و `#afa5a2` و `#f9f4ee`.

## النشر

`https://m0440145-svg.github.io/meetings/`

## المرحلة التالية
ربط تسجيل الدخول وقاعدة البيانات، إدارة الأعضاء، إنشاء الاجتماعات، المرفقات، التصويت، التوقيع الإلكتروني، التنبيهات، المحاضر والمهام.
