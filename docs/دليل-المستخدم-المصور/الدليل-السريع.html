الدليل السريع لمنصة الاجتماعات

جمعية الإحسان للخدمات الاجتماعية · الإجراءات الأكثر استخدامًا · الإصدار 0.2 (مسودة)

1) إنشاء اجتماع

  1. اضغط ＋ اجتماع جديد أعلى القائمة.
  2. اكتب العنوان واختر الجهة / اللجنة.
  3. حدد التاريخ ووقتي البداية والنهاية.
  4. اختر نوع الحضور والمنصة وألصق رابط https.
  5. أضف المحاور بـ ＋ إضافة محور وارفع الملفات.
  6. اختر قنوات التذكير وساعاته.
  7. اضغط حفظ وجدولة الاجتماع مرة واحدة.

2) دعوة الأعضاء وتسجيل الحضور

  1. افتح «الاجتماعات».
  2. في لوحة «الحضور والدعوات» اختر الاجتماع.
  3. اضغط إرسال الدعوات لأعضاء اللجنة (مرة واحدة لكل عضو).
  4. لتسجيل الحضور اختر الحالة ثم تسجيل حضوري.

3) تعديل اجتماع أو حذفه

  1. في صف الاجتماع اضغط إدارة.
  2. «تعديل البيانات» للتعديل، «＋ بند» للمحاور، «＋ مرفق» للملفات.
  3. «＋ رابط التسجيل» لحفظ رابط تسجيل الاجتماع مع تاريخ الاحتفاظ.
  4. «حذف الاجتماع» نهائي، فاستخدمه للمكرر فقط.

4) إدارة الأعضاء

  1. الحوكمة ← الأعضاء. اضغط بطاقة الجهة لعرض أعضائها.
  2. ابحث بالاسم أو الجوال أو البريد.
  3. ＋ إضافة عضو يدويًا لعضو بلا حساب.
  4. استيراد من Excel: نزّل «نموذج Excel» من «اللجان»، املأه، ثم ارفعه (حتى 500 صف).

5) التصويت

  1. الحوكمة ← التصويت والنصاب.
  2. اختر الاجتماع، واكتب الموضوع، واختر معلن أو سري، وحدد النصاب.
  3. اضغط فتح التصويت للأعضاء.
  4. يصوّت العضو مرة واحدة بعد تسجيل حضوره.

6) المحضر والتوقيع

  1. الحوكمة ← محاضر الاجتماعات.
  2. اختر الاجتماع واكتب نص المحضر والتوصيات.
  3. وقّع في المربع (مسح التوقيع للإعادة).
  4. اضغط حفظ المحضر.

7) الاستبيانات واستطلاع الموعد

  1. الحوكمة ← الاستبيانات ← «＋ استبيان جديد» (أو «استطلاع المواعيد» لاختيار موعد).
  2. أضف الأسئلة واحفظ مسودة.
  3. اضغط «نشر» ليصل إشعار للأعضاء.
  4. «النتائج» تعرض الأعداد وتصدّر Excel، وفي استطلاع الموعد اعتمد الموعد الفائز.

8) الإشعارات والجوال

  1. الجرس 🔔 أعلى الصفحة لإشعاراتك.
  2. مساحة العضو ← تفضيلات التنبيه لاختيار القنوات ورقم الجوال.
  3. على الهاتف: ☰ لفتح القائمة، و🌙 للوضع الداكن.
