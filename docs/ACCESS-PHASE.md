# مرحلة ضبط الوصول — 2026-10-14

الحالة: فرع مراجعة، غير منشور وغير مطبق على قاعدة الإنتاج.

## المنفذ
- `database/proposals/access-hardening.sql`: قيود إضافية على الأدوار وعضوية اللجان والاجتماعات والمرفقات والتخزين. لا يحذف بيانات أو سياسات سابقة. يمنع تغيير نطاق الاجتماع واستبدال الملفات الموجودة من المتصفح.
- `supabase-app.js`: التحقق من المستخدم والحساب النشط قبل فتح الواجهة.
- `advanced-supabase.js`: إيقاف إنشاء ملف نصي على أنه توقيع رسمي، مع إبقاء مدخل التوقيع وشرح حاجته للربط الخارجي. الرسم في النموذج لا يُرسل كتوقيع معتمد.
- اختبارات PostgreSQL معزولة باستخدام PGlite، واعتماد مثبت في package-lock.json. لا تتصل بالإنتاج.

## أدلة الاختبار وحدودها
`npm ci --ignore-scripts` ثم `npm test`.
اختبارات RLS تستخدم حسابات وهمية داخل قاعدة مؤقتة فقط، مع سياسات أولية واسعة للتأكد أن القيود الجديدة لا يمكن تجاوزها بسياسة permissive أخرى.
تشمل: عزل الملفات والاجتماعات، منع ترقية الدور، منع الرفع غير المصرح، منع استبدال الملفات، منع نقل نطاق الاجتماع، سحب وصول الحساب الموقوف.
لا تمثل هذه اختبارات أجهزة فعلية أو Supabase Storage API أو دورة اجتماع كاملة.

## قبل تطبيق SQL
هذه مسودة SQL مختبرة على نموذج جداول معزول وليست ترحيل إنتاج معتمدًا. يجب:
1. إنشاء بيئة Supabase اختبار مستقلة واستعادة المخطط الكامل دون بيانات شخصية.
2. إنشاء migration بأداة Supabase CLI وإجراء فحص advisors.
3. مراجعة الأدوار الحالية وتوحيد role/role_code. قواعد الوصول تستخدم role الحالي، ولا تغيّر قيمه تلقائيًا.
4. توفير مسار إدارة موثوق لإنشاء الحسابات وتعديل الأدوار؛ تحديث الحقول الحساسة من المتصفح ممنوع حتى للمدير في هذه المرحلة.
5. اختبار عضويات اللجان ومدير المنصة وإدارة الأعضاء على المخطط الكامل. القيود لا تمنح صلاحية غير موجودة في السياسات القديمة.
6. حصر الملفات اليتيمة أو ذات المسارات القديمة؛ لا تُحذف. الملفات غير المرتبطة بسجل مرفق/توقيع لا تُتاح تلقائيًا.
7. نسخة احتياطية واسترجاع تجريبي مع الملفات الفعلية، ثم مراجعة واعتماد النشر.

## المتبقي، غير مدّعى اكتماله
- نقل الوظائف المحلية إلى قاعدة مركزية وترحيل آمن للبيانات المحلية.
- ضوابط النصاب والتصويت السري وقفل المحاضر وسجل تدقيق خادمي شامل.
- ربط Parq بمواصفة API ومفاتيح خادمية وتحقق webhook.
- اختبار البريد وواتساب مع إعدادات مزود ومستلمين مخصصين.
- استرجاع نسخة احتياطية حقيقية ودورة اجتماع عبر متصفحات/أجهزة مختلفة.
- لم تُنشأ بيئة Supabase فرعية: أداة تقدير التكلفة غير متاحة؛ لم تُنشأ موارد مدفوعة.
