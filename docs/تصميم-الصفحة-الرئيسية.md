# دليل تصميم الصفحة الرئيسية (للزائر قبل تسجيل الدخول)

الملف المنفَّذ: `landing.js` (البنية والتنسيق والسلوك) + `banners-admin.js` (إدارة الإعلانات) + الترحيل `supabase/migrations/006_platform_banners.sql`.
**لم أُنتج ملفات Figma/Adobe XD**: لا أستطيع إنشاؤها من هنا. المنفَّذ صفحة حيّة بكود حقيقي، ويمكن تصديرها إلى Figma بأي مكوّن إضافي لاستيراد HTML (مثل html.to.design) إن احتجت إطارات تصميم.

## 1) الهيكل والتخطيط
```
┌─ لوحة الدخول (يسار، 400px، قابلة للطي) ─┬──────────── المحتوى (يمين) ─────────────┐
│  ✕                                       │ [شعار + اسم المنصة]  أهداف رؤية رسالة تواصل │ ← ترويسة ثابتة
│  شعار / عنوان                            │ ┌──────────── البنر المتحرك 8:3 ─────────┐ │
│  البريد  [..........]                    │ │ عنوان كبير · نص · [زر]                  │ │
│  كلمة المرور [.......] إظهار              │ │            ‹ السابق ● ○ ○ التالي  إيقاف │ │
│  [ تسجيل الدخول ]                        │ └──────────────────────────────────────┘ │
│  [ الدخول برمز OTP ]                      │ أهدافنا: 4 بطاقات بأيقونات                │
│  — أو —  [ المتابعة عبر Google ]          │ [ رؤيتنا (داكنة) ] [ رسالتنا (فاتحة) ]    │
│  إنشاء حساب · نسيت كلمة المرور             │ شريط دعوة: «هل أنت عضو؟» [تسجيل الدخول]  │
└──────────────────────────────────────────┴ تذييل: من نحن · تواصل · تابعنا ───────────┘
```
- **سطح المكتب (≥ 900px):** اللوحة مفتوحة افتراضيًا وتدفع المحتوى 400px. عند طيّها تظهر لسان رأسي «تسجيل الدخول» على الحافة اليسرى وزر في الترويسة.
- **الجوال/اللوحي (< 900px):** اللوحة ورقة سفلية (Bottom sheet) مغلقة افتراضيًا، تُفتح بزر الترويسة ويغلقها زر ✕ أو Esc.
- **نقاط التوقف:** 560 / 700 / 900 / 1100 بكسل. لا تمرير أفقي في أي مقاس (مُختبر على 390 و1360).
- بعد تسجيل الدخول تختفي الصفحة العامة وتظهر المنصة كالمعتاد.

## 2) البنر المتحرك والإعلانات
| البند | القيمة |
|---|---|
| النسبة | 8:3 على سطح المكتب (صورة 1600×600)، وارتفاع أدنى 340px على الجوال (النص أهم من الصورة) |
| الوزن | الصورة ≤ 250 كيلوبايت بصيغة WebP (الحد الأقصى للرفع 2 م.ب) |
| الانتقال | تلاشي (opacity) 0.7 ثانية، بلا تحريك لخصائص التخطيط، فلا يُكلّف المعالج |
| التبديل التلقائي | كل 7 ثوانٍ (المدى الموصى به 6–8)، ويتوقف عند المرور بالمؤشر أو التركيز أو إخفاء التبويب أو ضغط «إيقاف» |
| تقليل الحركة | من يفضّلون ذلك (`prefers-reduced-motion`) لا يبدأ عندهم التبديل ولا التلاشي |
| الأداء | تُحمَّل الصورة الأولى فورًا ثم الشريحة التالية فقط قبل ظهورها؛ مؤقّت واحد؛ لا مكتبات خارجية |
| العدد | حتى 8 إعلانات (الأفضل 3–5) |
| التحكم الإداري | صفحة «بيانات المنصة» ◂ «إعلانات الصفحة الرئيسية»: عنوان، نص، صورة (رابط أو رفع)، رابط وزر، ترتيب، تفعيل، تاريخ بدء وانتهاء |
| الأمان | روابط https فقط، النصوص تُعرض نصًا لا HTML، وسياسات RLS تجعل القراءة العامة للفعّال فقط |
| إرشادات المحتوى | عنوان ≤ 80 حرفًا ونص ≤ 200؛ زر واحد؛ صورة بلا نص مكتوب عليها (النص من الشريحة)؛ تباين عالٍ بفضل الطبقة الداكنة |
| بلا إعلانات | تظهر 3 شرائح افتراضية (ترحيب، قيمة، أمان) |
| الحيوية | حركة دخول متتالية للنص (0.12 ثانية بين العناصر)، تقريب بطيء للخلفية (Ken Burns 18 ثانية)، أشكال عائمة ودائرة تدور ببطء، نبض حلقي على الزر، تأثير بارالاكس خفيف مع المؤشر (سطح المكتب)، عدّاد "01 / 03" وشريط تقدم متزامن مع التبديل |
| وضع ثلاثي الأبعاد (تجريبي) | CSS 3D فقط بلا مكتبات: انتقال دوراني بين الشرائح بعمق، ومجسّم أوراق زجاجية عائم بثلاث طبقات يميل مع المؤشر، وطبقات خلفية/نص بأعماق مختلفة. يعمل على الشاشات ≥ 900px ولمن لا يفضّلون تقليل الحركة، وزر «3D» يوقفه ويحفظ الاختيار |
| الإيقاف التلقائي للحركة | خارج الشاشة، وعند إخفاء التبويب، وعند المرور بالمؤشر، وبزر «إيقاف»، وتُلغى كلها مع تقليل الحركة |

## 3) الأهداف والرؤية والرسالة
- **الهرمية البصرية:** الأهداف 4 بطاقات متساوية بأيقونة دائرية ونص موجز ◂ الرؤية بطاقة داكنة بارزة (الأعلى) ◂ الرسالة بطاقة فاتحة ◂ دعوة لتسجيل الدخول.
- **المحتوى:** من «بيانات المنصة» (الأهداف سطر لكل هدف، الرؤية، الرسالة، من نحن، التواصل، الترخيص، روابط التواصل). **النصوص الافتراضية مؤقتة** وصيغت بشكل عام؛ استبدلها بنصوص الجمعية المعتمدة قبل الإطلاق.
- **قابلية القراءة:** عناوين ≤ 32px، نص 16–24px، عرض النص ≤ 60 حرفًا، تباعد أسطر 1.8.

## 4) لوحة تسجيل الدخول (يسار)
- **حركة:** انزلاق 0.3 ثانية بـ `transform` فقط. المغلقة `visibility:hidden` فلا تُركَّز بلوحة المفاتيح.
- **حقول:** `autocomplete` صحيح (`username` و`current-password` / `new-password`)، زر إظهار/إخفاء كلمة المرور، تنبيه Caps Lock.
- **الأخطاء:** نص واضح بـ `role=alert` (يُقرأ بقارئ الشاشة). رسالة الدخول الفاشل **موحّدة** ولا تكشف إن كان البريد مسجلًا.
- **قيود أمنية:** تبطيء 30 ثانية بعد 5 محاولات خاطئة (إرشادي من المتصفح)، وحدود Supabase، وتنويه للمستخدم. الحماية الفعلية تتطلب في Supabase: **تعطيل التسجيل الذاتي**، وتفعيل CAPTCHA (Turnstile) و MFA، وسياسة كلمات مرور قوية.
- **الدخول الاجتماعي:** مدعوم عبر `oauthProviders` في `supabase-config.js` (google / azure / apple / github). يبقى مخفيًا حتى تُفعّل المزوّد في Supabase وتضيف اسمه. ننصح بالمزوّدات المؤسسية (Microsoft/Google Workspace) وتقييد النطاق في المزوّد.

## 5) الهوية البصرية والوصول (WCAG 2.2 AA)
| الدور | اللون | التباين المحسوب |
|---|---|---|
| الأساسي للزينة والعناصر الكبيرة | `#cf6028` | 3.9:1 على الأبيض (للنص الكبير فقط) |
| **الأساسي للنص والأزرار** | `#a8461a` | **5.9:1** على الأبيض |
| البرتقالي الثانوي (تدرجات وتمييز) | `#f18927` | 6.2:1 على الداكن |
| الخلفية الدافئة | `#f9f4ee` | النص `#3a332f` عليها 11.3:1 |
| النص الثانوي | `#6b5f59` | 6.2:1 على الأبيض |
| الداكن للأقسام والتذييل | `#2b211c` | النص الفاتح عليه 14:1 |
| الرمادي الدافئ `#afa5a2` | **للخطوط والزينة فقط** (2.4:1 لا يصلح للنص) |
- **الخط:** خط النظام (Segoe UI / Tahoma) لسرعة التحميل وعدم الاعتماد على الشبكة. للهوية يُوصى باستضافة خط عربي (Tajawal أو IBM Plex Sans Arabic) محليًا في `assets/` مع `font-display:swap` ثم إضافة `font-src 'self'` المسموح أصلًا.
- **حركات دقيقة:** رفع البطاقة 4px عند المرور، ضغط الأزرار 0.98، تحوّل لون سلس 0.2 ثانية، ظهور تدريجي للأقسام عند التمرير. كلها `transform`/`opacity` وتُعطَّل مع تقليل الحركة.
- **الوصول:** رابط «تخطي إلى المحتوى»، بنية عناوين صحيحة (h1 اسم المنصة في الترويسة، وh2 للأقسام والإعلانات)، `aria-roledescription=carousel`، أزرار تحكم بأسماء واضحة، زر إيقاف التبديل (متطلب 2.2.2)، حلقة تركيز 3px، لا اعتماد على اللون وحده، أهداف لمس ≥ 36px.

## 6) دليل المطورين
| الملف | الدور |
|---|---|
| `landing.js` | يبني الصفحة، ويحقن تنسيقها، ويدير البنر ولوحة الدخول. يُحمَّل بعد `supabase-app.js` |
| `banners-admin.js` | واجهة المدير لإدارة الإعلانات |
| `supabase/migrations/006_platform_banners.sql` | جدول `platform_banners` وسياساته (يعتمد على 001 و002) |
| `supabase-config.js` | `oauthProviders` |
| `index.html` | `data-auth` على `<html>`: `pending` (إخفاء المنصة لحين معرفة الجلسة) ◂ `out` (صفحة عامة) / `in` (المنصة) / `error` |
- **الربط:** المحتوى يقرأ `platform_settings` (anon) و`platform_banners` (anon، الفعّال فقط). عند غياب الجدول أو الإعلانات تُعرض النصوص الافتراضية.
- **التخصيص السريع:** ثوابت `AUTOPLAY_MS` و`DEFAULT_*` أعلى `landing.js`، والألوان متغيرات CSS في بداية `CSS`.
- **اختبارات يدوية مقترحة:** لوحة المفاتيح (Tab/Esc/أسهم)، قارئ شاشة، تقليل الحركة، 390/768/1360، تعطيل الشبكة (يجب أن تظهر الشرائح الافتراضية)، إعلان منتهي الصلاحية (لا يظهر).

## 7) الأصول المطلوبة
شعار SVG نهائي (الحالي مؤقت في `assets/logo.svg`)، 3–5 صور إعلانات WebP 1600×600، نصوص الأهداف والرؤية والرسالة المعتمدة، بيانات التواصل والترخيص، أيقونة التبويب (favicon)، وخط عربي مرخّص للاستضافة المحلية.
